| Término | Significado |
|---|---|
| Alumno | Persona gestionada por la academia |
| Profesor | Persona que dicta disciplinas |
| Disciplina | Actividad/oferta con profesor, salón y horarios |
| Inscripción | Vínculo alumno–disciplina con estado y fecha |
| Planilla mensual | Agrupación de asistencia de disciplina/período |
| Asistencia diaria | Registro individual por fecha |
| Tarifa | Precio de disciplina con fecha efectiva |
| Condición económica | Ajuste aplicable a una inscripción por vigencia |
| Matrícula | Cargo anual asociado al alumno |
| Mensualidad | Obligación periódica |
| Cargo | Deuda liquidada y aplicable |
| Liquidación | Cálculo trazable de un cargo |
| Snapshot | Datos históricos congelados al liquidar/exportar |
| Aplicación de pago | Asignación de parte de un pago a un cargo |
| Crédito | Saldo a favor gestionado por movimientos |
| Caja | Resumen de ingresos/egresos en rango |
| Egreso | Salida de caja anulable |
| Stock | Producto/inventario vendible |
| Reversión | Operación compensatoria que conserva historia |
| Baja lógica | Desactivación sin borrado físico |
| Recibo | PDF y metadata asociados al pago |
| Vigencia | Intervalo/fecha desde la cual aplica una regla |
| Fecha de negocio | Fecha civil calculada en timezone configurado |
| RBAC | Control de acceso por roles y permisos |
| Permiso funcional | Código requerido para una capacidad |
| `PERM_APP_ACCESO` | Permiso base para cualquier función de aplicación |
| Access token | JWT bearer de corta duración |
| Refresh session | Sesión persistida que rota refresh tokens |
| Checkpoint | UUID de snapshot Jere Platform |
| Cursor | Token opaco de paginación de exportación |
| `GESTUDIO_STUDENT` | Tipo externo mínimo de referencia de alumno |
| Source of truth | Fuente autoritativa: código/migraciones/config |
| Demo persistente | Stack local aislado que conserva volumen |
| Certificación integral | Inventario + smoke aislado + demo pública |
| GATE-1B | Validación de liquidación financiera por vigencia |
| GATE-2 | Recorrido/aceptación humana, históricamente separado |
