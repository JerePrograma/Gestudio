Seguí estos pasos aunque nunca hayas usado Gestudio ni una aplicación de gestión.

  1. Encendé la computadora. Esperá a que Windows termine de iniciar.
  2. Buscá Google Chrome. Hacé doble clic sobre su ícono.
  3. Ubicá la barra de direcciones. Es la franja larga que está arriba de la página. No es el cuadro de búsqueda que puede aparecer en el centro.
  4. Escribí o pegá esta dirección: https://gestudio-demo-jere-287b8c90.pages.dev/
  5. Presioná Enter. Esperá hasta ver la pantalla de ingreso de Gestudio.
Nueva pestañaUsá el botón + de Chrome para abrir otra página sin cerrar el manual.
VolverLa flecha hacia la izquierda vuelve a la pantalla anterior. No la uses para deshacer una operación guardada.
RecargarPresioná F5 o el botón circular de recarga si una pantalla quedó detenida.
El botón Atrás no anula cambiosSi guardaste un pago, una inscripción u otro dato, volver a la página anterior no lo elimina. Consultá el historial y usá sólo la acción de corrección autorizada para tu perfil.
