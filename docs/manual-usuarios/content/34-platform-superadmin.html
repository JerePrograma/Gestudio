La cuenta demo ya está configurada. Para obtener sus códigos en tu teléfono, agregá manualmente la clave TOTP que figura en Credenciales de la demo. Esto no cambia la cuenta ni inicia un alta nueva.

Agregar la clave demo a una aplicación autenticadora

  1. En tu teléfono, abrí Google Authenticator, Microsoft Authenticator u otra aplicación compatible con códigos TOTP.
  2. Presioná el signo + o la opción para agregar una cuenta.
  3. Elegí Ingresar clave de configuración, Entrada manual o el nombre equivalente.
  4. Como nombre de cuenta, podés escribir Gestudio Demo - Plataforma.
  5. Copiá la clave TOTP DEMO mostrada en el capítulo de credenciales y pegala en el campo de clave.
  6. Si la aplicación pregunta el tipo, elegí Basada en tiempo.
  7. Guardá la cuenta. La aplicación empezará a mostrar un código de 6 dígitos que cambia periódicamente.

Ingresar a la plataforma

  1. Abrí el enlace de administración de plataforma.
  2. Completá Nombre de usuario y Contraseña.
  3. En Segundo factor, dejá seleccionada la opción Aplicación.
  4. Escribí el código de 6 dígitos que muestra tu teléfono.
  5. Presioná Acceder al control plane.
  6. Si el código cambió justo antes de confirmar, esperá el siguiente e intentá nuevamente.
Usá solamente la opción Aplicación en esta demo. Dejala seleccionada como segundo factor. Para acciones especialmente sensibles, Gestudio puede pedir otro código nuevo durante la sesión.
