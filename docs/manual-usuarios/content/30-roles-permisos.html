Los roles reúnen permisos para que varias personas con la misma responsabilidad reciban accesos consistentes.

Rol

Representa una función de trabajo, por ejemplo Secretaría o Caja.

Permiso

Representa una acción concreta, como consultar alumnos, registrar asistencias o administrar usuarios.

Acceso real en la demo Sólo SUPERADMIN de la academia puede abrir Seguridad > Roles. ADMINISTRADOR y DIRECCIÓN administran usuarios, pero no crean ni modifican roles.

Qué muestra el listado

La pantalla Roles y permisos informa código, nombre, estado, tipo y cantidad de permisos. Los roles base del sistema están protegidos; sirven como referencia y no se modifican desde el formulario.

Crear un rol personalizado

  1. Entrá en Seguridad > Roles y presioná Nuevo rol.
  2. Escribí un Código claro y único. Una vez creado, el código no se cambia.
  3. Completá Nombre y, si ayuda, una Descripción funcional.
  4. En Permisos, revisá los grupos y marcá al menos una opción.
  5. Comprobá que el conjunto corresponda a una tarea real y presioná Guardar.
  6. El nuevo rol aparecerá en el listado como Personalizado y podrá asignarse a usuarios autorizados.

Editar o desactivar un rol personalizado

  1. En el listado, elegí Editar.
  2. Actualizá el nombre, la descripción, los permisos o la opción Rol activo.
  3. Presioná Guardar. El código queda fijo para mantener una referencia estable.
  4. Si el rol ya no debe asignarse, usá Desactivar y confirmá.
Evitá permisos “por las dudas”. Un rol debe incluir únicamente lo necesario. Antes de cambiarlo, recordá que la modificación afecta a las personas que lo tienen asignado.
Beneficio para la academia Los roles permiten aplicar una misma política de acceso a puestos similares y ajustar responsabilidades sin configurar cada acción persona por persona.
