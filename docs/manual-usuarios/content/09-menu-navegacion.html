El menú organiza las tareas diarias, la administración, la gestión académica, los reportes y la seguridad.

Accesos diarios

Alumnos, Cobranza, Pagos y Caja aparecen directamente cuando el perfil los permite.

Administración

Agrupa Egresos, Métodos de pago, Conceptos y Stock.

Gestión académica

Agrupa Inscripciones, Asistencias, Profesores, Disciplinas, Salones, Bonificaciones y Recargos.

Seguridad

Puede mostrar Usuarios y, sólo para el SUPERADMIN de la academia, Roles.

  1. Hacé clic una vez sobre el nombre de un grupo para abrirlo.
  2. Elegí la opción que corresponde a tu tarea.
  3. Leé el título de la pantalla antes de completar datos.
  4. Usá Volver o el menú para continuar con otra tarea.
  5. Cuando termines, presioná Cerrar sesión.
