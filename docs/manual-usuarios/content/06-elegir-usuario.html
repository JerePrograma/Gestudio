Elegí la cuenta según lo que quieras conocer. Gestudio adapta el menú y las acciones disponibles para que cada persona trabaje con lo necesario.

Primera visita

Usá alpha.demo.presentacion. Permite recorrer información de Escuela Danza Marcos Paz sin mostrar funciones de administración o cambios sensibles.

Atención y secretaría

Usá demo-secretaria para alumnos, inscripciones, asistencias, cobranza y consultas habituales.

Cobros y caja

Usá demo-caja para buscar alumnos, registrar cobros y consultar pagos, recibos, caja y stock.

Administración

Usá demo-administrador o demo-direccion para recorrer la gestión completa, salvo la administración de roles.

Configuración de la academia

Usá demo-superadmin cuando necesites mostrar usuarios, roles y permisos dentro de Escuela Danza Marcos Paz.

Separación entre academias

Compará alpha.demo.admin con beta.demo.admin. Cada cuenta entra a una organización distinta y ve solamente sus datos.

Administración de la plataforma

Usá platform.demo.admin únicamente para organizaciones, accesos globales y auditoría. No sirve para las tareas diarias de una academia.

Decisión rápida

  1. Si querés una presentación general, elegí la cuenta de Primera visita.
  2. Si querés entender un puesto de trabajo, elegí Secretaría, Caja, Administración o Dirección.
  3. Si querés comprobar que dos academias no mezclan información, recorré primero Alpha y después Beta.
  4. Si querés administrar organizaciones, usá el ingreso separado de plataforma.
ADMINISTRADOR y DIRECCIÓN tienen los mismos permisos en la demo actual. Los nombres representan responsabilidades distintas dentro de la academia, aunque hoy muestran las mismas funciones. Ninguno de los dos administra roles.
Hay dos cuentas Administrador para Alpha con el mismo alcance. alpha.demo.admin se usa para comparar Alpha con Beta; demo-administrador se usa en el recorrido por puestos de trabajo.
